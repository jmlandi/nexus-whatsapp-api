## 📞 Support

### Documentation Issues
- Found an error? Open an issue on GitHub
- Need clarification? Check [Troubleshooting](./19-TROUBLESHOOTING.md)
- Missing information? Refer to external resources above

### Application Issues
- Check `/health` endpoint: `http://localhost:3000/health`
- Review logs: `logs/combined.log`
- Enable debug mode: `LOG_LEVEL=debug` in `.env`
